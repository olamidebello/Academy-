Updates and connectivity

This is an installable web app (PWA), not an Android APK or an App Store release. The latest platform features load when you open the app online. Login, exams, saving records and clocking require an internet connection. Location permission is requested only for clocking actions.

To remove Academy, use your device’s app or home-screen settings.
